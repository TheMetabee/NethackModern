NetHack Modern sound effects
============================

These files are played by the miniaudio sound library (sound/miniaudio)
in response to presentation events (src/fx.c) and the core's own sound
effects. At run time the game looks for them in a "sounds" folder next
to the executable; the Windows package step copies this folder there.

Naming:
  <name>_N.wav      variations of one sound; one is picked at random
  se_<name>_N.wav   plays when the game triggers sound effect <name>
                    from include/seffects.h (for example se_canine_howl)
  death_<kind>_N    a death cry layered over the body-fall thud, chosen
                    by monster class (see ma_death_cry() in masound.c)

All files were converted to 16-bit mono 44.1 kHz WAV and renamed; unless
noted, the audio is otherwise unchanged. Some source clips are used under
more than one name.

Licensing summary: the Kenney and rubberduck packs are CC0 (public
domain). The AHTu20 and TomMusic packs are royalty-free for use in games
but must not be resold or redistributed as standalone sound packs; they
are included here only as part of this game.
